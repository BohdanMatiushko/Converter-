# Конвертер електричних величин

Desktop-застосунок на Python для конвертації електричних величин з сучасним графічним інтерфейсом.

## Можливості

- одиночна конвертація
- масова конвертація
- автоконвертація при редагуванні
- експорт таблиці у Excel
- табличний інтерфейс у стилі простої Excel-сітки
- підсвічування помилкових рядків
- status bar з повідомленнями

## Підтримувані одиниці

### Струм
- A
- mA
- µA

### Напруга
- V
- mV
